## Group Projects

The Applied Data Science program at University of Michigan requires completion of two Milestone projects and a Capstone.  The first project focuses on data analysis fundamentals and data visualization.  The second project requires students to master a variety of supervised and unsupervised machine learning (ML) techniques.  The Capstone project is more open-ended, with final deliverables including a project visualization summary, a demonstration video, and a written report or blog.

 - Milestone I: Our team of three students applied fundamental data science methods to test a hypothesis whether latitude correlates with depression. We defined the problem, explored, cleaned and transformed relevant data, and then applied basic statistical methods to test the hypothesis. The code and final report, which includes custom visualizations developed using popular Python libraries including Matplotlib and Plotly, are available in this repository under the [Data-Analysis-Viz](https://github.com/kingpete99/Reports-Projects/tree/main/Data-Analysis-Viz) folder.

 - [Milestone II](https://github.com/tmacpherson6/machine_learning_in_fundamental_valuations): Our team of three applied supervised and unsupervised ML techniques to predict future revenue for companies using publicly available financial data from Yahoo Finance.

 - [Capstone](https://github.com/tmacpherson6/investment_advisor_dashboard_capstone) (i/p): Our team of four is developing a tool that a financial advisor can use to generate an investment portfolio that aligns with a client's estimated risk tolerance. First we estimate a client's risk tolerance using a brief survey that considers factors such as age and marital status. We then use a variety of ML and deep-learning models to forecast volatility for selected Exchange Traded Funds (ETF) that are representative of different market sectors. Finally, we use a portfolio generation algorithm to develop a recommended set of investments that aligns with the client's estimated risk tolerance.
